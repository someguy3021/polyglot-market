# Polyglot Market

**Один API-контракт — 2 бекенда — 7 фронтов.** Маркетплейс, собранный как ультимативная fullstack-витрина: тот же магазин, та же база, те же фичи — дважды на бекенде (Laravel и NestJS) и семь раз на фронтенде (Vue 3 + Quasar, Vue 2, Angular, React, Nuxt, Next.js, SvelteKit) — с доказательством исполняемыми тестами, что фреймворки взаимозаменяемы.

> 🚧 **Статус: blueprint.** Архитектура, дизайн контракта и roadmap готовы (см. [`docs/`](docs/README.md)); реализация стартует фазой 1. Этот README вырастет в quick-start для рекрутера по мере появления кода.

## Идея

- **Контракт-первым.** `shared/api-spec/openapi.yaml` — единственный источник правды. Все 9 приложений общаются через него; conformance-сьют доказывает байт-совместимость обоих бекендов.
- **Один активный бекенд.** Laravel или NestJS — никогда не оба. Останови один, запусти другой: тот же фронт, те же данные, ноль правок кода.
- **Реальный домен.** Не todo-лист: маркетплейс с четырьмя ролями — покупатель, продавец, модератор, админ — гостевая корзина с мерджем при логине, промокоды, способы доставки, жизненный цикл заказа, идемпотентный checkout, загрузка картинок в S3-совместимое хранилище.
- **В одну команду.** `pnpm doctor && pnpm setup && pnpm start` — веб-панель управления поднимает любые комбинации бекендов и фронтов с живыми логами.
- **Docker там, где ему место.** PostgreSQL + MinIO всегда в контейнерах; процессы приложений — нативно (WSL2 / Linux / macOS). Контейнерные комбо «1 фронт + 1 бекенд» тоже — но никогда «всё сразу».
- **Фабрика.** `pnpm extract --front=react --back=nestjs` превращает монорепу в автономный репозиторий под один стек — мегарепа это станок, экстракты — продукция.

## Требования (план)

Linux, macOS или Windows через **WSL2** · Node.js (LTS, пин в `.nvmrc`) · pnpm · Docker · PHP 8.4+ и Composer (только для Laravel-бекенда) · Java **не** требуется (сгенерированные клиенты коммитятся).
