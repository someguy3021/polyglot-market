# AGENTS.md — Polyglot Market (megarepo витрина)

> **Суть:** точка входа для ИИ-агентов. L0-файл: читать целиком перед любой работой.
> **Связанное:** [docs/README.md](./docs/README.md) — карта и панель «Сейчас»

Монорепа-витрина «1 API — 2 бекенда (Laravel, NestJS) — 7 фронтов (quasar, vue2, angular, react, nuxt, next, sveltekit)»: маркетплейс с общим OpenAPI-контрактом, общей PostgreSQL и MinIO, панелью управления процессами и фабрикой автономных экстракт-репо. Тир dev-standard: T2. Ключевые принципы: контракт — источник правды; активен один бекенд; явные `pnpm doctor/setup/start` без postinstall-магии; целевая платформа WSL2/Linux/macOS (Windows — только через WSL2); везде TypeScript на Node-стороне. Сейчас репа — blueprint: дока готова, кода ещё нет (фаза 1 не начата).

## Окружение (проверка перед работой)

| Что | Команда |
|---|---|
| Проверка окружения | `pnpm doctor` *(план фазы 1)* |
| Установка/настройка | `pnpm setup` *(план)* |
| Инфраструктура (postgres+minio) | `pnpm infra:up` / `pnpm infra:down` *(план)* |
| Миграции / сиды | `pnpm db:migrate` / `pnpm db:seed` *(план)* |
| Запуск/дев (панель :5555) | `pnpm start` *(план)* |
| Юнит-тесты | `pnpm test` *(план)* |
| E2E-матрица (фронт × бекенд) | `pnpm test:e2e --front=<имя> --back=<имя>` *(план)* |
| Линт / типы | `pnpm lint` / `pnpm typecheck` *(план)* |
| Контракт: линт и клиенты | `pnpm spec:lint` / `pnpm generate:clients` *(план)* |
| Docker-комбо «1 фронт + 1 бек» | `pnpm docker:up --front=<имя> --back=<имя>` *(план)* |
| Фабрика экстрактов | `pnpm extract --front=<имя> --back=<имя>` *(план)* |

Особенности: порты — панель 5555, laravel 8000, nestjs 3000, quasar 9000, vue2 9001, angular 4200, react 3001, nuxt 3002, next 3003, sveltekit 3004, postgres 5432, minio 9002 (console 9003). Секреты — только в локальных `.env` (из `.env.example`); демо-пароль `password` — только для сидов. Один активный бекенд одновременно (ADR-006). Схема БД меняется ТОЛЬКО общими SQL-миграциями `shared/db/migrations` (ADR-002) — artisan-миграции и TypeORM synchronize запрещены. Сгенерированный SDK `packages/api-client` коммитится; перегенерация требует Java (ADR-004). Windows-native не поддерживается — WSL2 (ADR-009).

## Уровни чтения

- **L0 (всегда):** этот файл + [docs/README.md](./docs/README.md).
- **L1 (при взятии задачи):** шапки релевантных доков по карте + последний `docs/log/` +
  активные вопросы из `docs/open-questions.md`.
- **L2 (по необходимости):** тела доков, опции ADR, протоколы решений. Шапки — до тел.

## Как искать

1. Тема → карта в `docs/README.md` → шапка → тело.
2. Символ/файл кода → grep по имени в `docs/`.
3. «Что сейчас» → панель «Сейчас» + последний log.

## Правила

- Язык: идентификаторы — английский; комментарии и доки — русский.
- Стиль кода: `docs/architecture/NN-code-style.md` **[обязательно для агентов]** (появится в фазе 1).
- Архитектуру менять только с ADR — в момент решения.
- Требования автора фиксируются дословно, протоколом решений в фича-доке (источник — опрос из 40 вопросов, 2026-10-19).
- Каждый новый эндпоинт контракта = conformance-кейсы в том же PR (ADR-005).
- Если есть docs/ui-freeze.md — его статусы абсолютны: 🔒🔒 не редактировать вообще
  (спроси автора), 🔒 — только убедившись, что автор этого хочет.
- Ссылки на код в доках — от корня репы, имена символов.
