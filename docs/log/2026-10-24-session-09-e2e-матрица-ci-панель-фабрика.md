## Найденные и исправленные баги фронтов (все — до E2E «работали» только на бумаге)

- **vue2**: не был вызван `Vue.use(VueRouter)` — router-link неизвестен, навигации не было.
- **next**: `||` вперемешку с `??` без скобок в client-api (синтаксическая ошибка, клиентский API не собирался);
  `useParams` без импорта на карточке; пустой `category=` в fetchCatalog → 422 → RSC 500; карточка товара
  не сохраняла `x-cart-token` гостевой корзины; OrderStatus/SellerProduct касты в prod-сборке.
- **nuxt**: useSession импортировал `api`, которого нет в useApi (логин/корзина/добавление — TypeError);
  cart/checkout не грузили корзину при прямой загрузке (useState пуст).
- **sveltekit**: страница товара вечно «Загрузка…» ($effect не выполняется без data.id) → универсальный load;
  session.svelte.ts звал незавезённый errorMessage.
- **angular**: захардкоженный `:8000` в checkout; `<base href>` отсутствовал — прямая загрузка глубоких
  маршрутов тяла `/seller/main.js` → 404; корзина не грузилась при F5.
- **react**: checkPromo падал `cart!.subtotal` при null-cart (гонка загрузки) — guard + ожидание в спеке.
- **quasar**: admin-тест стучался в несуществующий нативный select (QSelect — меню); показывал сырое `paid`.

## Грабли сессии

- WSL-VM циклится при простое: postgres/s3rver падали посреди прогонов (симптом: `ECONNREFUSED 127.0.0.1:9002`
  в db:reset, затем ливень 401 «Invalid credentials»). Лечится `pnpm infra:up`; раннер теперь делает это сам.
- Гонки SSR-гидратации (sveltekit/nuxt/next): клик до гидратации теряется — networkidle-ожидания,
  clickUntil-ретраи (sveltekit), ожидание POST-ответа (next: `goto /cart` отменял in-flight `/cart/items`).
- Холодная компиляция next-маршрутов в dev съедала 60с-таймаут — test.setTimeout(180_000) для roles.next.
- Стейл дев-серверы прошлых сессий слушали порты фронтов (3002 отвечал vue2!) — killPort всех фронтовых
  портов перед дебагом; тесты против «чужого» фронта давали невозможные селекторы.
- `Assertion failed: !(handle->flags & UV_HANDLE_CLOSING) src\win\async.c` — шум libuv при гашении
  процессов на Windows ПОСЛЕ зелёных тестов; на результат не влияет.
