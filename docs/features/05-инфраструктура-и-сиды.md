## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| Рекрутер | `pnpm doctor && pnpm setup && pnpm start` — больше ничего |
| Бекенды | общий Postgres (порт 5432), MinIO (S3 API, порт 9002) |
| E2E | детерминированные сиды как fixture |

## 2. Сценарии

1. `pnpm doctor`: Node/pnpm/Docker есть? PHP есть (warning, если нет)? WSL2-детект на Windows-native → внятный отказ.
2. `pnpm infra:up` → postgres 17.x + minio, healthchecks, бакет `products` создаётся автоматически.
3. `pnpm db:migrate` → SQL-миграции по журналу с чексуммами; `db:seed` → роли, товары (сгенерированные картинки заливаются в MinIO), промокоды.
4. `pnpm setup` = install + .env + migrate + seed — идемпотентен, безопасно перезапускать.

Демо-аккаунты (в README и на логин-страницах фронтов):
`buyer@demo.dev` / `seller@demo.dev` / `moderator@demo.dev` / `admin@demo.dev` — общий пароль `password` (только локальная демо-среда, сидами).

Порты (нативный режим): панель 5555, laravel 8000, nestjs 3000, quasar 9000, vue2 9001, angular 4200, react 3001, nuxt 3002, next 3003, sveltekit 3004, postgres 5432, minio 9002 (console 9003).
