> **Статус:** В ПЛАНЕ · **Обновлено:** 2026-10-19

**Суть:** SSR-фронт на актуальном Nuxt: Nuxt UI, composables поверх SDK, серверные вызовы API по абсолютному URL.

**Ключевое:** решений в протоколе: 2 · этапов: 6

## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| Все 4 роли | полный функционал в SSR-режиме |

## 2. Сценарии

Паритет с фичей 07 + специфика SSR:
- каталог рендерится на сервере (`useAsyncData`), API URL на сервере — абсолютный (`NUXT_PUBLIC_API_URL`).
- корзина/сессия — `useCookie`/state (SSR-безопасно), мердж при логине.
- гидратация: idempotent-рендер, чтобы не было вспышек.
- Nuxt UI — каноничный кит. Порт 3002.
