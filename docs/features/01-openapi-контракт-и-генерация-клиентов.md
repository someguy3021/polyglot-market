# Фича: OpenAPI контракт и генерация клиентов

> **Статус:** В ПЛАНЕ · **Обновлено:** 2026-10-19

**Суть:** `shared/api-spec/openapi.yaml` — единственный источник правды для 2 бекендов и 7 фронтов; из него генерируется общий TypeScript SDK.

**Ключевое:** решений в протоколе: 4 · этапов: 5

**Связанное:** [ADR-004](../decisions/adr-004-openapi-3-0-3-и-генерация-sdk-typescript-axios.md) · [ADR-005](../decisions/adr-005-conformance-тесты-контракта-в-v1.md) · [ADR-011](../decisions/adr-011-идемпотентность-заказов-через-idempotency-key.md) · features/14

## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| Laravel-бекенд | справочник эндпоинтов/ошибок для FormRequest и роутов |
| NestJS-бекенд | TS-модели (генерация) + справочник для DTO |
| 7 фронтов | `@showcase/api-client` (typescript-axios) как единственный слой API |
| conformance/e2e | схема для валидации ответов |
| ИИ-скринер / рекрутер | читает спецификацию как главный документ API |

## 2. Сценарии

1. Мейнтейнер правит `openapi.yaml` → `pnpm generate:clients` → дифф в `packages/api-client` → все фронты получают типы.
2. CI проверяет, что SDK закоммичен и не протух (`git diff --exit-code` после перегенерации).
3. Spectral линтит спецификацию (набор правил: обязательные описания, единые ошибки, пагинация).
4. Рекрутер открывает Swagger UI: бекенд отдаёт `/api/docs` (статика из openapi.yaml + элементы).

Эндпоинты контракта (полный фарш сразу — решение №3):
`auth/register`, `auth/login`, `auth/me` · `products` (пагинация, фильтры: категория/цена/поиск/продавец/статус; сортировка), `products/{id}`, `categories` · `cart` (гостевая по `cart_token`, мердж при логине) · `orders` (+ `Idempotency-Key`), `orders/{id}` · промокоды (проверка), способы доставки · загрузка изображений · admin: товары, заказы, пользователи, модерация · `health`, `docs`.

Единый формат ошибок `{ status, error, message, details }`, пагинация `{ data, meta }`, даты ISO 8601 UTC, JWT bearer.

## 3. Протокол решений

| № | Дата | Вопрос | Решение |
|---|---|---|---|
| 1 | 2026-10-19 | Версия OpenAPI | 3.0.3 — стабильнее для генераторов (автор: «без разницы») |
| 2 | 2026-10-19 | Генератор для SDK | typescript-axios → `@showcase/api-client` (автор: «на твой вкус») |
| 3 | 2026-10-19 | Объём контракта v1 | «полный фарш» сразу: фильтры, сортировка, /health, /api/docs (автор: «да, сразу полный фарш») |
| 4 | 2026-10-19 | Идемпотентность POST /orders | в контракте с v1, заголовок Idempotency-Key (автор: «НУЖЕН, мы за ним гонимся») |

## 5. НЕ-цели

- GraphQL-слой, WebSocket-нотификации — за рамками v1 (кандидаты в v2).
- Автогенерация PHP-стабов из контракта.
