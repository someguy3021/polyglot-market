# Фича: Фронт Vue 2 Vite

> **Статус:** В ПЛАНЕ · **Обновлено:** 2026-10-19

**Суть:** полноценный фронт на Vue 2.7 (последняя линия, Composition API) + Vite + Vuetify 2 — осознанная демонстрация владения legacy-экосистемой.

**Ключевое:** решений в протоколе: 3 · этапов: 5

**Связанное:** [ADR-004](../decisions/adr-004-openapi-3-0-3-и-генерация-sdk-typescript-axios.md) · features/02, 07

## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| Все 4 роли | полный функционал (паритет с флагманами) |

## 2. Сценарии

Паритет с фичей 07 на Vue 2.7: Composition API (без `<script setup>`-специфики Vue 3), Vuetify 2 как канон Vue 2, Vuex вместо Pinia, Vue Router 3. Vite через `@vitejs/plugin-vue2`. TypeScript строго. Порт 9001.
