## 2. Сценарии (сценарий видео)

1. (0:00) Титул: «1 API — 2 бекенда — 7 фронтов». README глазами: 3 команды.
2. `pnpm doctor && pnpm setup && pnpm start` — панель открывается.
3. Запуск quasar + laravel: регистрация, корзина, промокод, заказ.
4. Стоп Laravel → старт NestJS → тот же фронт продолжает работать, заказ виден.
5. Админка: смена статуса заказа; модерация товара.
6. `pnpm extract` → готовый репо → открывается у себя.
7. Финал: CI-бейджи, ссылки.

Формат: экран 1920×1080, озвучка RU + субтитры EN (или наоборот — см. открытый вопрос), выкладывается в README ( YouTube/Vimeo embed).
