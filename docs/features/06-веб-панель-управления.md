# Фича: Веб-панель управления

> **Статус:** РЕАЛИЗОВАНА (ждёт верификации автора) · **Обновлено:** 2026-10-25

**Суть:** локальный HTTP-менеджер процессов (порт 5555) с красивой TypeScript-панелью: карточки приложений, логи с уровнями и скачиванием, таблица портов с автоподбором, инвариант «один бекенд».

**Ключевое:** решений в протоколе: 5 · этапов: 6

**Связанное:** [ADR-003](../decisions/adr-003-явные-pnpm-setup-doctor-start-вместо-postinstall.md) · [ADR-006](../decisions/adr-006-один-активный-бекенд-одновременно.md) · [ADR-009](../decisions/adr-009-целевая-платформа-wsl2.md) · features/05

## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| Рекрутер | запускает/останавливает комбинации кликами, смотрит логи, переходит по портам |
| Автор | быстрый старт любого комбо при разработке |

## 2. Сценарии

1. `pnpm start` → менеджер поднимается, открывает браузер; если setup не выполнен — кнопка «Run setup».
2. Карточки: laravel, nestjs + 7 фронтов + infra-статус (postgres/minio). Кнопки старт/стоп, ссылка «Открыть».
3. Попытка запустить второй бекенд при живом первом → диалог «остановить текущий?» (ADR-006).
4. Логи: живой хвост последних N строк с подсветкой уровней (error/warn), кнопка «скачать полный лог».
5. Конфликт порта: таблица приложений показывает фактический порт; при занятом — автоподбор свободного (и это видно в UI).
6. Статус обновляется polling'ом `/api/status` (2 сек) — или SSE, если poll окажется дёрганым.

API менеджера: `POST /api/start`, `POST /api/stop`, `GET /api/status`, `POST /api/stop-all`, `GET /api/logs/:app` (+ download).

Стек панели: Vite + Vue 3 + TypeScript, собранный бандл раздаёт менеджер. Реализация менеджера — Node/TypeScript (spawn с POSIX-сигналами, ADR-009).

## 5. НЕ-цели
