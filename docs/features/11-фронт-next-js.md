## 2. Сценарии

Паритет с фичей 07 + специфика App Router:
- каталог/карточка товара — Server Components (fetch с абсолютным `NEXT_PUBLIC_API_URL` на сервере, `revalidate` для кэша).
- корзина, checkout, кабинеты — клиентские компоненты на SDK.
- middleware для auth-редиректов; shadcn/ui + Tailwind — каноничный для Next-мира кит. Порт 3003.
