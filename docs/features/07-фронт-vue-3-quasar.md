# Фича: Фронт Vue 3 Quasar

> **Статус:** В ПЛАНЕ · **Обновлено:** 2026-10-19

**Суть:** флагманский фронт №1: Vue 3 + Quasar, полный функционал маркетплейса для всех четырёх ролей.

**Ключевое:** решений в протоколе: 3 · этапов: 7

**Связанное:** [ADR-004](../decisions/adr-004-openapi-3-0-3-и-генерация-sdk-typescript-axios.md) · features/02, 08

## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| Покупатель/продавец/модератор/админ | полный кабинет каждой роли |
| Рекрутер | эталон качества UI витрины |

## 2. Сценарии

1. Каталог: сетка товаров, фильтры (категория/цена/поиск), пагинация — через `@showcase/api-client`.
2. Гостевая корзина → логин → мердж → checkout (промокод, доставка) → заказ с Idempotency-Key.
3. Продавец: CRUD товаров + загрузка картинок + повторная отправка на модерацию.
4. Модератор: очередь approve/reject с причиной. Админ: заказы/статусы/пользователи/промокоды.

Стек: Quasar компоненты (каноничный кит этого фронта — решение в. 22), Pinia (корзина/сессия), Vue Router, TypeScript. Порт 9000.
