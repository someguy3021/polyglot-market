## 2. Сценарии

1. `pnpm start` в панели → «Laravel» → `php artisan serve --port=8000` против общего Postgres.
2. Все эндпоинты контракта; ошибки строго в едином формате.
3. Загрузка картинки: валидация (тип/размер) → MinIO → превью Intervention → запись в `product_images`.
4. Юнит-тесты сервисов корзины/заказа/промокодов (PHPUnit).

Детали реализации:
- Версии — актуальные stable на день старта кода (ориентир: PHP 8.4+, Laravel 12+); пины в `composer.json`.
- Миграции НЕ через artisan — общие SQL (ADR-002); в README бекенда — пояснение.
- JWT — `php-open-source-saver/jwt-auth`; роли — middleware/gates по `users.role`.
- Медиа — `flysystem-aws-s3-v3` + `intervention/image`.
- Rate limiting на auth-эндпоинтах; CORS — конфигурируемый списком origins фронтов.
- `/api/docs` — статический Swagger UI, отдающий `openapi.yaml`.
