# Фича: CI стратифицированный

> **Статус:** РЕАЛИЗОВАНА (ждёт верификации автора) · **Обновлено:** 2026-10-25

**Суть:** GitHub Actions, ubuntu: быстрые проверки на каждый push, полная e2e-матрица 2×7 — по расписанию (nightly/weekly), подключается в конце разработки.

**Ключевое:** решений в протоколе: 3 · этапов: 5

**Связанное:** [ADR-005](../decisions/adr-005-conformance-тесты-контракта-в-v1.md) · features/14, 16

## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| ИИ-скринер | бейджи + история зелёных прогонов = доказательство живости репы |
| Автор | регресс до коммита |

## 2. Сценарии

1. **PR / push:** lint (eslint+prettier, spectral) → typecheck → юниты (PHPUnit, Jest) → conformance против обоих бекендов → smoke-e2e одной пары (quasar × nestjs). Время цели — ≤10 мин.
2. **Ночная полная матрица:** 2 × 7 e2e + сборка docker-комбо (выборочно). Бейдж матрицы в README.
3. **SDK-дрифтер:** после правок `openapi.yaml` — перегенерация, `git diff --exit-code packages/api-client` (ADR-004).
4. Кэши pnpm/composer; Postgres/MinIO — сервис-контейнеры джобы.

## 3. Протокол решений

| № | Дата | Вопрос | Решение |
|---|---|---|---|
| 1 | 2026-10-19 | Полная матрица на каждый push | нет — быстро/стабильно сейчас (автор: «быстрее и стабильнее»), полная матрица в конце разработки (в. 36) |
| 2 | 2026-10-19 | ОС раннеров | ubuntu = целевой среде (ADR-009) |
| 3 | 2026-10-19 | Docker в CI | только проверки сборок, e2e — нативно против сервис-контейнеров БД |
