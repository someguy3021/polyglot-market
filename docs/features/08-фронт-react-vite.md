# Фича: Фронт React Vite

> **Статус:** В ПЛАНЕ · **Обновлено:** 2026-10-19

**Суть:** флагманский фронт №2: React + Vite, полный функционал маркетплейса для всех ролей.

**Ключевое:** решений в протоколе: 3 · этапов: 7

**Связанное:** [ADR-004](../decisions/adr-004-openapi-3-0-3-и-генерация-sdk-typescript-axios.md) · features/02, 07

## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| Все 4 роли | полный кабинет (паритет с Quasar-фронтом) |
| Рекрутер | второй эталон качества |

## 2. Сценарии

Паритет сценариев с фичей 07 (каталог/корзина/checkout/роли), реализованный идиомами React:
серверное состояние — TanStack Query (запросы, кэш, инвалидация), клиентское (корзина, сессия) — Zustand, роутинг — React Router, UI — MUI.

Стек: React (актуальный major) + Vite + TypeScript. Порт 3001.
