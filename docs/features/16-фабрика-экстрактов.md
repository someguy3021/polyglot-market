# Фича: Фабрика экстрактов

> **Статус:** РЕАЛИЗОВАНА (ждёт верификации автора) · **Обновлено:** 2026-10-25

**Суть:** `pnpm extract --front=react --back=nestjs` генерирует автономный репозиторий «1 фронт + 1 бекенд + shared»: со своим README, lockfile, опциональным CI и чистым git — выглядит самостоятельным проектом под стек вакансии.

**Ключевое:** решений в протоколе: 4 · этапов: 5

**Связанное:** [ADR-010](../decisions/adr-010-фабрика-экстрактов-публична-и-с-lockfile.md) · features/01, 05, 15

## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| Автор | отклик на вакансию: паблик-репо под нужный стек за минуты |
| Рекрутер | самодостаточный проект: `pnpm doctor && pnpm setup && pnpm start` |
| ИИ-скринер | чистый, протестированный, самодостаточный репо без следов «склейки» |

## 2. Сценарии

1. `pnpm extract --front=react --back=nestjs --out=../ecommerce-react-nestjs` → папка-репо: backend, frontend, shared, packages, scripts (нужные), infra, panel; свой package.json/pnpm-workspace.yaml/README (EN).
2. `--dry-run` печатает план копирования/генерации, ничего не создавая.
3. `--ci` добавляет workflow (lint+юниты+conformance+smoke этой пары).
4. Внутри экстракта: `git init` + «Initial commit» (свежая дата, честная история — ADR-010).
5. Самопроверка фабрики: экстракт каждой из 14 пар поднимается по своему README (e2e фабрики).

Фильтры: `.env`, секреты, артефакты, `docs/` (мегарепа-специфика), не относящиеся фронты/бекенды. Lockfile: перенос pnpm-lock с пере-снапшотом под усечённый воркспейс.
