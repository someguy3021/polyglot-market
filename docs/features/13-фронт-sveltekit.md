# Фича: Фронт SvelteKit

> **Статус:** В ПЛАНЕ · **Обновлено:** 2026-10-19

**Суть:** полноценный фронт на SvelteKit (Svelte 5, runes): полный покупательский путь и кабинеты ролей — «шестое чувство» мегарепы.

**Ключевое:** решений в протоколе: 2 · этапов: 5

**Связанное:** [ADR-004](../decisions/adr-004-openapi-3-0-3-и-генерация-sdk-typescript-axios.md) · features/02, 10

## 1. Суть и потребители

| Потребитель | Как пользуется |
|---|---|
| Все 4 роли | полный функционал (паритет с флагманами) |

## 2. Сценарии

Паритет с фичей 07 идиомами Svelte 5: runes (`$state`, `$derived`) для корзины, load-функции для данных (SDK в `+page.ts`), form actions для auth, guards в `+layout.ts` ролей. UI-кит — см. открытый вопрос (Skeleton UI / daisyUI). Порт 3004.
