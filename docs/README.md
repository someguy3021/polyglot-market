# Polyglot Market — Документация

> **Статус:** живая карта · **Обновлено:** 2026-10-19 · **Тир:** T2 (dev-standard v1.10)
> **Суть:** карта всей документации + панель текущего состояния. L0-файл: агент читает всегда, первым после AGENTS.md.
> **Связанное:** [../AGENTS.md](../AGENTS.md)

Монорепа-витрина для вакансий: интернет-маркетплейс (4 роли: покупатель/продавец/админ/модератор) с единым OpenAPI-контрактом, двумя бекендами (Laravel, NestJS) и семью фронтами (Quasar, Vue 2, Angular, React, Nuxt, Next, SvelteKit), общей PostgreSQL+MinIO, веб-панелью управления и фабрикой автономных экстракт-репо. Ключевое обещание: один и тот же фронт работает с любым бекендом без единой правки — доказано conformance-тестами и e2e-матрицей 2×7. Приоритетный читатель — ИИ-скринер (решение автора, 2026-10-19).
