## Решённые вопросы

- **СУБД двух режимов** → PostgreSQL везде, infra в Docker (2026-10-19, фиксация: [ADR-001](./decisions/adr-001-postgresql-как-единственная-субд-во-всех-режимах.md)).
- **Владелец миграций** → общие SQL + Node-раннер (2026-10-19, [ADR-002](./decisions/adr-002-общие-sql-миграции-с-node-раннером.md)).
- **postinstall-магия** → явные doctor/setup/start (2026-10-19, [ADR-003](./decisions/adr-003-явные-pnpm-setup-doctor-start-вместо-postinstall.md)).
- **Версия контракта и генератор** → 3.0.3 + typescript-axios, SDK в git (2026-10-19, [ADR-004](./decisions/adr-004-openapi-3-0-3-и-генерация-sdk-typescript-axios.md)).
- **Доказательство совместимости** → conformance-тесты в v1 (2026-10-19, [ADR-005](./decisions/adr-005-conformance-тесты-контракта-в-v1.md)).
- **Режим бекендов** → один активный (2026-10-19, [ADR-006](./decisions/adr-006-один-активный-бекенд-одновременно.md)).
- **Docker-режим** → только комбо «1 фронт + 1 бек», сборка из корня (2026-10-19, [ADR-007](./decisions/adr-007-docker-только-комбо-профилями-из-корня-репо.md)).
- **Картинки товаров** → MinIO + upload + превью с v1 (2026-10-19, [ADR-008](./decisions/adr-008-медиа-minio-с-первого-дня.md)).
- **Платформа** → WSL2/Linux/macOS (2026-10-19, [ADR-009](./decisions/adr-009-целевая-платформа-wsl2.md)).
- **Фабрика экстрактов** → публичная, lockfile, честная история (2026-10-19, [ADR-010](./decisions/adr-010-фабрика-экстрактов-публична-и-с-lockfile.md)).
- **Идемпотентность** → Idempotency-Key на POST /orders (2026-10-19, [ADR-011](./decisions/adr-011-идемпотентность-заказов-через-idempotency-key.md)).
- **Состав фронтов** → 7 шт: quasar, vue2, angular, react, nuxt, next, sveltekit; vue2 и svelte обязательны («Это же megarepo») (2026-10-19, фиксация: features/07–13).
- **Роли** → маркетплейс: покупатель/продавец/админ/модератор (2026-10-19, фиксация: features/02).
- **Инструменты React-фронта** → Vite + TanStack Query + Zustand + MUI (2026-10-19, фиксация: features/08).
