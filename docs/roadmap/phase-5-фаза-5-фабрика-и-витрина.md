# Roadmap — Фаза 5: фабрика и витрина

> **Статус:** НЕ НАЧАТА · **Обновлено:** 2026-10-19

**Суть:** упаковка экспоната: панель до «fancy», фабрика экстрактов, полная CI-матрица, README EN/RU, видео — и публикация.

**Цель:** репа публикуется: рекрутер запускает за 5 минут или смотрит видео; автор генерирует экстракт под вакансию одной командой.

Границы фазы:
- Новые фичи домена не добавляются; только упаковка и проверка.

## Критерии готовности

1. Чистый клон → 3 команды → работающий магазин (проверено на свежей WSL2-машине).
2. `pnpm extract` для любой пары даёт поднимающийся репозиторий.
3. Бейдж полной матрицы зелёный; видео встроено в README.
