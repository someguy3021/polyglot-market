# Roadmap — Фаза 2: первый сквозной путь

> **Статус:** НЕ НАЧАТА · **Обновлено:** 2026-10-19

**Суть:** флагманская пара «Laravel + Vue 3 Quasar» доводит маркетплейс до полного покупательского и ролевого цикла.

**Цель:** живой маркетплейс на флагманской паре: покупатель проходит от каталога до заказа с промокодом и доставкой, все 4 роли отрабатывают свои кабинеты, conformance покрывает весь API.

Границы фазы:
- NestJS — фаза 3; остальные 6 фронтов — фаза 4; панель — минимально рабочая (старт/стоп/логи), полировка — фаза 5.

## Этапы

### 2.1 — Laravel до полного паритета с контрактом (фича 03)

- [ ] Каталог/корзина/заказы/идемпотентность
- [ ] Промокоды, доставка
- [ ] Медиа: upload + превью (ADR-008)
- [ ] Кабинеты seller/moderator/admin
- [ ] Юнит-тесты сервисов (cart, order, promo)

### 2.2 — Quasar-фронт (фича 07)

- [ ] Каталог + фильтры + карточка
- [ ] Гостевая корзина + мердж + checkout
- [ ] Auth + guards
- [ ] Кабинеты всех ролей

### 2.3 — Доказательства

- [ ] Conformance: все эндпоинты, позитивные и негативные кейсы
- [ ] E2E: гость + покупатель на паре quasar × laravel (фича 14)

## Критерии готовности

1. Все conformance-кейсы против Laravel зелёные.
2. E2E покупательского пути на quasar × laravel зелёный.
3. Ручной сценарий из фичи 02 (товар от продавца до заказа покупателя) воспроизводим на чистых сидах.

## Осознанные НЕ-цели фазы

- Отзывы/рейтинги, споры, выплаты (НЕ-цели домена, фича 02).
