# Roadmap — Фаза 2: первый сквозной путь

> **Статус:** В РАБОТЕ (2.1 готова) · **Обновлено:** 2026-10-19

**Суть:** флагманская пара «Laravel + Vue 3 Quasar» доводит маркетплейс до полного покупательского и ролевого цикла.

**Цель:** живой маркетплейс на флагманской паре: покупатель проходит от каталога до заказа с промокодом и доставкой, все 4 роли отрабатывают свои кабинеты, conformance покрывает весь API.

Границы фазы:
- NestJS — фаза 3 (auth-каркас уже есть); остальные 6 фронтов — фаза 4; панель — минимально рабочая (старт/стоп/логи), полировка — фаза 5.

## Этапы

### 2.1 — Laravel до полного паритета с контрактом (фича 03)

- [x] Каталог/корзина/заказы/идемпотентность
- [x] Промокоды, доставка
- [x] Медиа: upload + превью (ADR-008) — проверено вручную: upload 201, PNG из S3
- [x] Кабинеты seller/moderator/admin
- [ ] Юнит-тесты сервисов (cart, order, promo)

### 2.2 — Quasar-фронт (фича 07)

- [ ] Скелет Quasar + SDK + layout
- [ ] Каталог + карточка + фильтры
- [ ] Гостевая корзина + мердж + checkout
- [ ] Auth + guards роутера
- [ ] Кабинет продавца (товары, картинки)
- [ ] Кабинет модератора
- [ ] Кабинет админа

### 2.3 — Доказательства

- [x] Conformance: все эндпоинты, позитивные и негативные кейсы — 17/17 против Laravel
- [ ] E2E: гость + покупатель на паре quasar × laravel (фича 14)

## Критерии готовности

1. [x] Все conformance-кейсы против Laravel зелёные (17/17).
2. [ ] E2E покупательского пути на quasar × laravel зелёный.
3. [x] Ручной сценарий из фичи 02 (товар от продавца до заказа покупателя) воспроизводим на чистых сидах (проверено conformance-сценарием roles).

## Осознанные НЕ-цели фазы
