# Roadmap — Фаза 4: флот фронтов

> **Статус:** НЕ НАЧАТА · **Обновлено:** 2026-10-19

**Суть:** оставшиеся 6 фронтов догоняют Quasar до полного паритета функций; E2E-спеки переиспользуются всеми.

**Цель:** каждый из 7 фронтов проходит полный сценарный чеклист (фича 14) против обоих бекендов.

Границы фазы:
- Порядок: react (флагман №2) → angular → nuxt → next → vue2 → sveltekit.
- Панель и CI остаются как есть; полная CI-матрица — фаза 5.

## Критерии готовности

1. Один и тот же набор E2E-спек проходит на всех 7 фронтах × 2 бекенда (14 пар) локально.
2. Ни один фронт не содержит веток «если бекенд = X» — только контракт.

## Осознанные НЕ-цели фазы
