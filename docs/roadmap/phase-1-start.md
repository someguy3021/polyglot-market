# Roadmap — Фаза 1: фундамент

> **Статус:** НЕ НАЧАТА · **Обновлено:** 2026-10-19

**Суть:** скелет монорепы, контракт v1, инфраструктура и доказательный контур (conformance) — фундамент, без которого фронты начинать нельзя.

**Цель:** довести репу до состояния «`pnpm doctor && pnpm setup` работает, контракт собран и сверен, обе роли инфраструктуры поднимаются, conformance-раннер гоняет пустой сценарий против заглушки-бекенда».

Границы фазы:
- Бизнес-фичи (корзина, заказы, роли) — фаза 2; фронты — фазы 2–4; docker-комбо и фабрика — фаза 5.
- Пока реализуется один «реперный» бекенд-каркас (Laravel) — NestJS параллельно не начинаем.

## Этапы

### 1.1 — Скелет монорепы

- [ ] pnpm workspaces: `packages/*`, `backend/nestjs`, `frontend/*`; `packageManager`-пин, `.nvmrc`
- [ ] Общий tsconfig/base, eslint+prettier, conventional commits (привычка с первого коммита)
- [ ] Корневые скрипты-заглушки: doctor/setup/start/infra/db/generate/extract/test:e2e

### 1.2 — Контракт v1 (фича 01)

- [ ] `openapi.yaml`: auth, каталог, корзина, заказы, промокоды, доставка, медиа, admin, health
- [ ] Единые ошибки/пагинация/даты; Idempotency-Key в спецификации
- [ ] Spectral-конфиг + линт

### 1.3 — Инфраструктура (фича 05)

- [ ] `infra/docker-compose.infra.yml`: postgres + minio + healthchecks
- [ ] Node-раннер миграций + `schema_migrations`-журнал
- [ ] Схема маркетплейса v1 (фича 02): все таблицы ролей и статусных машин
- [ ] Сиды: аккаунты 4 ролей, категории, 40 товаров, картинки в MinIO, промокоды, доставка
- [ ] `pnpm doctor` / `setup` / `infra:up|down` / `db:migrate|seed`

### 1.4 — Доказательный контур (ADR-005)

- [ ] `packages/conformance`: каркас (fetch + ajv по схеме), сценарий health+auth
- [ ] Laravel-каркас: приложение, маппинг схемы, auth-эндпоинты
- [ ] conformance зелёный против Laravel

## Критерии готовности

1. Чистый клон в WSL2: `pnpm doctor && pnpm setup` проходит без единой ручной правки.
2. `pnpm db:migrate && pnpm db:seed` на пустой БД даёт полный маркетплейс-датасет с картинками в MinIO.
3. `spectral lint` и conformance (health+auth) зелёные в CI.
4. Логи решений: ADR-001..011 не противоречат коду.

## Осознанные НЕ-цели фазы

- Любые фронты, панель, docker-комбо, фабрика, видео.
- NestJS (только после того, как Laravel-каркас прошёл conformance).
