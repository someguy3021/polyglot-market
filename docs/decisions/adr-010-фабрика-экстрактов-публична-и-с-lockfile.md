# ADR-010: Фабрика экстрактов публична и с lockfile

> **Статус:** принято · **Дата:** 2026-10-19

**Суть:** `scripts/extract-stack.js` генерирует из мегарепы автономный репозиторий «1 фронт + 1 бекенд», выглядящий самодостаточным проектом. Скрипт публичен в мегарепе; экстракты получают честную свежую git-историю.

**Отвергнуто:** скрытие фабрики — при обнаружении выглядит хуже, чем публичный инструментарий; фейковая «длинная» история коммитов в экстрактах — обман, который вскрывается тривиально.

**Связанное:** [ADR-004](adr-004-openapi-3-0-3-и-генерация-sdk-typescript-axios.md) · features/16

## Контекст

Мегарепа — экспонат (решение автора в. 2), но для отклика на вакансии нужен репозиторий «как будто так и писали» под конкретный стек. ИИ-скринеры подозрительны и к мегарепам, и к «внезапным» репо без истории.

## Опции

### A. Скрывать фабрику, кастомизировать историю экстрактов

- Минусы: подделка истории вскрывается (даты, паттерны коммитов); этически проигрышно.

### B. Публичная фабрика + честные экстракты

- Плюсы: позиция «я автоматизировал производство демо-проектов» — сама по себе компетенция; мегарепа и экстракты ссылаются друг на друга.
- Минусы: тщательноcть README/тестов экстракта обязательна — «сгенерированность» не должна означать «сырость».

## Решение

**Вариант B.** Команда: `pnpm extract --front=react --back=nestjs --out=../<имя> [--ci] [--dry-run]`.

Что делает:
1. Копирует `backend/<back>`, `frontend/<front>`, `shared/`, `packages/`, `scripts/` (только нужные), `infra/`, `panel/`.
2. Генерирует: корневой `package.json`, `pnpm-workspace.yaml`, `README.md` (EN) под выбранный стек, `.env.example`, `.gitignore`.
3. Пересчитывает pnpm-lock.yaml под усечённый воркспейс (или переносит с пере-снапшотом).
4. Фильтрует `.env`, секреты, локальные артефакты.
5. `--ci`: добавляет GitHub Actions (lint + юниты + conformance + smoke-e2e этой пары).
6. `git init` + первый коммит «Initial commit» — свежая дата, без фальшивой давности.

## Обоснование

- Рекрутеру уходит экстракт; любопытный находит в профиле мегарепу с фабрикой — и это плюс, а не пятно.
- Честная история + паблик-фабрика устойчивы к любому скринеру.

## Последствия

**Позитивные:** 14 комбинаций по запросу без ручной поддержки; фабрика тестируется собственной матрицей (экстракт каждой пары поднимается по своему README — фича 16).

**Негативные / риски:**
- Экстракт дублирует панель и скрипты мегарепы — принимаем: самодостаточность важнее размера.
