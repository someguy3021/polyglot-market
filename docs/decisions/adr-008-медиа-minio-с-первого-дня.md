# ADR-008: Медиа MinIO с первого дня

> **Статус:** принято · **Дата:** 2026-10-19

**Суть:** изображения товаров загружаются через бекенд, хранятся в S3-совместимом MinIO (поднимается инфраструктурой), бекенд генерирует превью. Абстракция хранилища — чтобы MinIO подменялся настоящим S3 переменными окружения.

**Отвергнуто:** URL-строки в сидах (picsum) — «не серьёзно» для витрины; прямая загрузка из фронтов по presigned URL в v1 — усложняет оба бекенда без демонстрационной выгоды.

**Связанное:** [ADR-001](adr-001-postgresql-как-единственная-субд-во-всех-режимах.md) · features/02, 03, 04, 05

## Контекст

Решение автора (в. 25): «СРАЗУ с картинками и их хранилищем, все серьезно делаем». Маркетплейс без картинок товаров не выглядит настоящим; сиды должны заливать реальные изображения в хранилище.

## Опции

### A. Внешние URL в сидах

- Плюсы: ноль инфраструктуры.
- Минусы: нет сюжета «upload + хранилище + превью»; демо зависит от интернета.

### B. MinIO + upload через бекенд + превью

- Плюсы: полный путь медиа в обоих бекендах (flysystem+Intervention / aws-sdk+sharp); S3-совместимость = прод-переход через env; сиды заливают реальные файлы.
- Минусы: +1 контейнер инфраструктуры; бекенды делают одинаковую работу дважды (что и требуется).

## Решение

**Вариант B.** Эндпоинты загрузки в контракте: `POST /admin|seller/products/{id}/images` (multipart) и `DELETE .../images/{id}`. Хранилище: бакет `products` в MinIO (S3 API), ключи `{productId}/{uuid}.{ext}`, превью — отдельный суффикс `-thumb`. Конфиг через `S3_ENDPOINT/S3_BUCKET/S3_KEY/...` — подмена на облачный S3 без правок кода.

## Обоснование

- Загрузка через бекенд демонстрирует валидацию (тип/размер), генерацию превью и подписи URL — больший охват, чем presigned.
- MinIO — единственный «серьёзный» вариант, живущий локально без облака.

## Последствия

**Позитивные:** медиа-сюжет есть в обоих бекендах; сиды самодостаточны офлайн.

**Негативные / риски:**
- Инфраструктура выросла до postgres + minio; doctor обязан проверять/поднимать её до миграций (сидам нужен бакет).
- Ограничения: размер файла (5 МБ), типы (jpeg/png/webp) — фиксируются в контракте.

**Дополнение (2026-10-19, сессия 02):** на машинах с ограниченными сетями образ `minio/minio` может не пуллиться
(allowlist-посредники). `scripts/infra.mjs up` тогда поднимает postgres-контейнер + встроенный S3 dev-сервер
(s3rver, тот же S3 API на том же :9002) — потребители разницы не видят. Канонический путь — контейнер MinIO.
