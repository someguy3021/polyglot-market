# ADR-004: OpenAPI 3.0.3 и генерация SDK typescript-axios

> **Статус:** принято · **Дата:** 2026-10-19

**Суть:** контракт `shared/api-spec/openapi.yaml` в формате OpenAPI **3.0.3**; TypeScript SDK генерируется `openapi-generator` (generator `typescript-axios`) в workspace-пакет `@showcase/api-client`; сгенерированный код **коммитится в git**.

**Отвергнуто:** OpenAPI 3.1 — генераторы (typescript-axios и PHP-семейство) на 3.1 исторически нестабильны; генерация «на лету» у рекрутера — требует Java, убивает простоту запуска.

**Связанное:** [ADR-005](adr-005-conformance-тесты-контракта-в-v1.md) · features/01

## Контекст

Контракт — источник правды для 2 бекендов и 7 фронтов. `openapi-generator-cli` запускается через Java-рантайм; у рекрутера Java быть не должно. Решения автора: версия «без разницы» (в. 16), генератор «на твой вкус» (в. 17), TypeScript везде (в. 28).

## Опции

### A. OpenAPI 3.1 + генерация при установке

- Плюсы: свежий формат; сгенерённое не лежит в git.
- Минусы: баги генераторов на 3.1; Java как скрытое требование у каждого запускающего.

### B. OpenAPI 3.0.3 + сгенерированный SDK в git

- Плюсы: стабильная генерация; рекрутеру Java не нужен (перегенерация — забота мейнтейнера).
- Минусы: сгенерированный код в диффах; формат 3.0.3, а не 3.1.

## Решение

**Вариант B.** Цепочка: `openapi.yaml` → `pnpm generate:clients` → `packages/api-client/` (typescript-axios, `@showcase/api-client: workspace:*`) → подключается всеми 7 фронтами. TS-модели для NestJS — тем же генератором (только models). Laravel-валидация — рукописные FormRequest; их корректность гарантируют conformance-тесты (ADR-005), а не PHP-генерация стабов.

## Обоснование

- CI-джоба проверяет: перегенерация не даёт диффа (`git diff --exit-code packages/api-client`) — «SDK не протух» без Java у потребителей.
- typescript-axios работает во всех 7 фронтах, включая Vue 2 (axios — нейтральный рантайм).

## Последствия

**Позитивные:** один SDK на все фронты; правка контракта → перегенерация → все фронты получают типы сразу.

**Негативные / риски:**
- Сгенерированный код в репе — осознанно, помечен «DO NOT EDIT».
- Java нужен только контрибьюторам, меняющим контракт (в doctor — предупреждение, не ошибка).
